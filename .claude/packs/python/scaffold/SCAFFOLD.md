# python scaffold

How to create a Python API/service from scratch with **uv + FastAPI + ruff + pytest**. Flow confirmed for **uv 0.12.x and pytest 9 (July 2026)**. Complements the pack's `PACK.md` — read both before writing code.

## 0. Prerequisite

`uv --version` responds (install uv if not). Do not install Python by hand — uv downloads and manages the version by itself from `.python-version`.

## 1. Create the project

```bash
uv init PROJECT_NAME
cd PROJECT_NAME
```

The current `uv init` generates a **packaged** project (src/ + `uv_build` build backend). This scaffold uses a **non-packaged** app — simpler for an API that never becomes a library. Adjust like this:

1. **Replace** the generated `pyproject.toml` with the one from this scaffold and change the `name` field.
2. **Delete** `src/<generated_package>/` and copy from the scaffold: `src/app/`, `tests/`, `.env.example`, `.editorconfig`. Do not copy this `SCAFFOLD.md`.
3. **Keep** the `.python-version`, `README.md` and `.gitignore` generated by uv; check that `.env` is in `.gitignore` (add it if not).
4. Copy `.env.example` to `.env` and fill it in.

Because there is no `[build-system]`, the `app.*` imports work via `pythonpath = ["src"]` in `[tool.pytest]` and via the explicit path in the FastAPI CLI commands below. If one day the project needs to become an installable package, then reintroduce the build-system (decision recorded in ABOUT.md).

## 2. Add dependencies — always via uv, never loose pip

```bash
uv add "fastapi[standard]"
uv add --dev pytest ruff mypy
```

- `fastapi[standard]` brings the `fastapi` CLI (replaces `uvicorn ... --reload`) and the httpx used by the tests' `TestClient`.
- The first `uv add` creates `.venv/` and `uv.lock` — **commit the `uv.lock`**.
- Dev deps land in `[dependency-groups] dev` (PEP 735) and are synced by default.
- A new dep requires justification (PACK.md): if the stdlib solves it in a few lines, use the stdlib.

## 3. Run

| Command | What it does |
|---|---|
| `uv run fastapi dev src/app/main.py` | dev at `http://127.0.0.1:8000`, auto-reload ON, docs at `/docs` |
| `uv run fastapi run src/app/main.py` | production: `0.0.0.0:8000`, reload OFF (`--workers N` for multi-worker) |
| `uv run pytest` | tests |
| `uv run ruff check --fix .` | lint with autofix |
| `uv run ruff format .` | format (`--check` in CI) |
| `uv run mypy` | types — strict, scope defined in `[tool.mypy]` |

> **Windows note:** if `fastapi dev` crashes with `UnicodeEncodeError: 'charmap' codec...`,
> the console encoding is the culprit (the CLI prints unicode). Fix once with
> `setx PYTHONUTF8 1` (new shells) or prefix the command with `PYTHONUTF8=1`.
> Verified on Windows 11 — the app itself is unaffected.

## 4. Post-scaffold checklist

- [ ] `uv run fastapi dev src/app/main.py` starts and `GET http://127.0.0.1:8000/health` responds `{"status":"ok",...}`
- [ ] `uv run pytest` green (`/health` integration)
- [ ] `uv run ruff check .` and `uv run ruff format --check .` clean
- [ ] `uv run mypy` clean
- [ ] `uv.lock` committed; `.env` outside git
- [ ] ABOUT.md updated (section below)

## 5. Record in ABOUT.md

The ABOUT.md at the project root is the only file edited per project:

1. Line 2 becomes: `Active pack: python`
2. Under the `## Project commands` section, record:

```md
## Project commands
- `uv run fastapi dev src/app/main.py` — API at http://127.0.0.1:8000 (reload)
- `uv run pytest` — tests
- `uv run ruff check --fix .` and `uv run ruff format .` — lint + format
- `uv run mypy` — types
```

3. Any stack decision outside the pack default (legacy Flask/Django, venv+pip instead of uv, packaged project) goes under `## Constraints and notes`.

## 6. Next architecture steps (when the project grows)

- `src/app/config.py` with pydantic-settings (env validated at boot, fail fast) — mandatory at the first real env var; it is what loads the `.env`.
- Layers `routers/ → services/ → repositories/` with injection via `Depends`, plus `exceptions.py` — full structure in PACK.md.
- Automation script instead of an API? Same skeleton, without FastAPI: `main.py` becomes a CLI with a useful `--help`, `--dry-run` if destructive and correct exit codes (PACK.md).
- Database migrations only via Alembic.
